# frameUP 
---
## Cara Clone
*di terminal*
``git clone https://github.com/Shochibi/frameUP.git``
``cd frameUP``

## Set Up
*di terminal*
``composer install``
``npm install``
``cp .env.example .env``
``php artisan key:generate``

## Cara nge run *pake 2 terminal*
*terminal pertama*
``npm run dev``
*terminal kedua*
``php artisan serve``
*lalu buka*
``http://127.0.0.1:8000``
